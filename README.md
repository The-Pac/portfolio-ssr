# Portfolio SSR

## Overview

A personal portfolio website built with Server-Side Rendering (SSR) using Leptos and Axum, demonstrating modern Rust-based web development capabilities.

## Description

This project serves as both a functional developer portfolio and an exploration of cutting-edge Rust web technologies. By combining Leptos for reactive UI components with Axum as the backend framework, it delivers a fully server-rendered experience that prioritizes performance and developer experience.

## Technical Stack

### Frontend
- **Leptos**: Reactive web framework for building dynamic, server-rendered user interfaces

### Backend
- **Axum**: Ergonomic and modular web framework built on Tokio

### Architecture
- **Server-Side Rendering (SSR)**: Full page rendering on the server for optimal performance and SEO

## Features

- Fully server-rendered pages for improved initial load times
- Reactive UI components with Leptos
- High-performance backend powered by Axum and the Tokio runtime
- Modular, maintainable codebase designed for scalability
- SEO-optimized through server-side rendering
- Clean separation of concerns between frontend and backend logic

## Project Goals

This portfolio serves as a practical learning experience for exploring the Rust web ecosystem, particularly the emerging patterns around SSR and reactive frameworks. It demonstrates the viability of Rust for full-stack web development while maintaining the language's core principles of performance and safety.

## Project Status

This project is actively maintained as a personal portfolio and ongoing experiment with Rust web technologies.
