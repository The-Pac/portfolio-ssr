# portfolio-ssr

A personal portfolio project built using **Server-Side Rendering (SSR)** with [Leptos](https://github.com/leptos-rs/leptos) and [Axum](https://github.com/tokio-rs/axum), showcasing modern Rust-based web technologies.

## Description

`portfolio-ssr` is a developer portfolio built with a focus on performance and modern web architecture. It leverages the power of **Leptos** for reactive UI and **Axum** as the backend framework, offering a fully server-rendered experience. This project is a hands-on exploration of the latest trends in the Rust web ecosystem.

## Features

- ✅ Fully server-rendered frontend using **Leptos**
- 🔧 Backend powered by **Axum**
- 🚀 Lightning-fast performance with Rust
- 📄 Modular, clean architecture for easy scalability
- 🌐 SEO-friendly server-rendered pages
- 🧪 Ideal for learning and experimenting with SSR in Rust
